**Objective:** identify underappreciated investment opportunities in Indonesian palm oil equities before fundamental catalysts are fully priced in, combining fundamental and quantitative research.

## Structure

```
context/      shared project memory
research/     macro / industry / company notes
data/         raw and processed data, plus the source register
quant/        signals and factor models
valuation/    DCF, SOTP, comps, NAV models
backtests/    backtest code and results
outputs/      finished deliverables
tests/        tests for pipelines and models
```
